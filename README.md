# WagonHub · ВагонМесто

WagonHub — площадка для поиска и аренды мест отстоя железнодорожных вагонов. Владельцы путей публикуют свободные места и цену за вагон. Владельцы вагонов сравнивают предложения и подают заявки от имени своей компании. В каталоге видно, сколько вагонов площадка может принять сейчас.

## Как работает размещение

1. **Публикация площадки.** Владелец путей указывает город, адрес, вместимость и цену за вагон в рублях. Условия размещения можно уточнить в описании.
2. **Поиск и заявка.** Владелец вагонов заполняет карточку компании с названием, ИНН и рабочей почтой. В каталоге он выбирает город, нужное число свободных мест и предельную цену, затем указывает в заявке количество вагонов.
3. **Подтверждение.** Владелец путей видит контакты заявителя и подтверждает или отклоняет заявку в личном кабинете. Сервис фиксирует цену при подаче заявки, а места резервирует при подтверждении. Если два заявителя претендуют на последнее место, подтвердить можно только одну заявку.
4. **Освобождение мест.** После отъезда вагонов владелец путей завершает размещение. Число свободных мест увеличивается, а запись о сделке сохраняется в истории у обеих сторон.

## Быстрый старт

Склонируйте репозиторий и перейдите в каталог проекта.

```bash
git clone https://github.com/art4iba2/wagonhub-vercel.git
cd wagonhub-vercel
```

### Через Docker Compose

```bash
docker compose up --build -d
```

Откройте [WagonHub в браузере](http://localhost:8000). Для проверки сценария с обеих сторон создайте два аккаунта с разными адресами почты и выберите для них роли «Владелец путей» и «Владелец вагонов».

Чтобы остановить приложение, выполните `docker compose down`. База SQLite сохранится в томе `wagonhub_data`.

### Локально с Python

Для запуска нужен Python 3.14 или новее. Команды для macOS и Linux выполняются из корня проекта.

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
python -m uvicorn wagonhub.app:app --reload
```

Приложение доступно по адресу [localhost:8000](http://localhost:8000). При первом запуске в каталоге проекта создаётся база `wagonhub.db`.

## API

При локальном запуске полный список маршрутов, параметры запросов и схемы ответов доступны в [Swagger UI](http://localhost:8000/docs) и [ReDoc](http://localhost:8000/redoc).

| Действие | Метод | Маршрут |
| --- | --- | --- |
| Найти площадки по городу, числу свободных мест и цене | GET | `/api/listings` |
| Опубликовать площадку | POST | `/api/listings` |
| Изменить условия площадки | PUT | `/api/listings/{listing_id}` |
| Снять объявление | POST | `/api/listings/{listing_id}/withdraw` |
| Создать карточку компании | POST | `/api/company` |
| Подать заявку на размещение | POST | `/api/deals` |
| Подтвердить или отклонить заявку | POST | `/api/deals/{deal_id}/decision` |
| Завершить размещение и освободить места | POST | `/api/deals/{deal_id}/complete` |
| Посмотреть свои заявки и историю сделок | GET | `/api/my/deals` |

Например, этот запрос вернёт площадки, где свободно хотя бы пять мест и цена за вагон не превышает 2 000 ₽.

```bash
curl 'http://localhost:8000/api/listings?min_capacity=5&max_price=2000'
```

## Структура проекта

Сервер на FastAPI обслуживает HTTP API и отдаёт одностраничный интерфейс на HTML, CSS и JavaScript. Приложение поддерживает SQLite и PostgreSQL.

| Путь | Назначение |
| --- | --- |
| [wagonhub/app.py](wagonhub/app.py) | Маршруты, проверка ролей и операции с объявлениями и заявками |
| [wagonhub/db.py](wagonhub/db.py) | Схема базы, транзакции и блокировки при резервировании мест |
| [wagonhub/schemas.py](wagonhub/schemas.py) | Модели Pydantic для проверки входных данных |
| [wagonhub/static/](wagonhub/static/) | Каталог, формы, личный кабинет и уведомления |
| [tests/](tests/) | Тесты пользовательских сценариев, API и работы с базой |
| [pyproject.toml](pyproject.toml) | Зависимости приложения и настройки pytest |

## Тестирование

В активированном виртуальном окружении с зависимостями из группы `test` выполните команду ниже. Для локального прогона в конфигурации pytest задан порог покрытия 90 %.

```bash
python -m pytest
```

Для проверки одновременного подтверждения двух заявок на последнее место предусмотрен отдельный сценарий с PostgreSQL 17. Команда поднимает тестовую базу и возвращает код завершения тестов.

```bash
docker compose -p wagonhub-check -f compose.check.yaml up --build --exit-code-from tests
```
